MILITARY HUB — версія 2.0

ЗАПУСК ЛОКАЛЬНО:
1. Розпакуйте архів.
2. Відкрийте папку military_hub_site у Visual Studio Code.
3. Відкрийте index.html у браузері або використайте розширення Live Server.

ФАЙЛИ:
- index.html — головна сторінка та картки розділів
- style.css — дизайн, адаптивність та анімації
- script.js — інтерактивність першої картки

ПІДКЛЮЧЕНО:
- Побажання
- Проблемні питання
- Генератор

Картка «Пройоб дрона» поки показує повідомлення. Надане посилання на форму включало поля з координатами та оперативними обставинами, тому його не підключено. Можна додати нову погоджену адміністративну форму лише для обліку майна без оперативних подробиць.

ПУБЛІКАЦІЯ:
Для простого статичного сайту підійде GitHub Pages:
1. Створіть новий репозиторій на GitHub.
2. Завантажте в корінь репозиторію index.html, style.css, script.js.
3. Відкрийте Settings → Pages.
4. У Build and deployment виберіть Deploy from a branch.
5. Виберіть branch main і папку /(root), натисніть Save.
6. Дочекайтеся публікації та відкрийте адресу, яку покаже GitHub Pages.

УВАГА: GitHub Pages робить сайт публічним. Не додавайте до репозиторію паролі, приватні дані, внутрішні документи або службову інформацію. Перевірте налаштування доступу до кожної Google-форми окремо. Публічна сторінка не означає, що всі Google-форми автоматично відкриті для всіх.
